# Полное руководство: Настройка Termux с нуля и запуск VPS Toolkit 📱 🚀

Подробный пошаговый мануал для настройки чистого Termux на Android без root-прав и развёртывания **Android VPS Toolkit**.

---

## ⚠️ Шаг 0. Откуда правильно устанавливать Termux

> **Важнейшее предупреждение:**  
> **Никогда не устанавливайте Termux из Google Play Store!**  
> Версия в Google Play официально заброшена разработчиками с 2020 года из-за ограничений политики Google. В ней отключены обновления, и при первой же попытке выполнить `pkg install` вы получите ошибки `Repository under maintenance` или `404 Not Found`.

### ✅ Официальные источники для загрузки актуального Termux:
1. **F-Droid (Рекомендуется):**  
   Скачайте APK со страницы [f-droid.org/packages/com.termux/](https://www.google.com/search?q=https%3A%2F%2Ff-droid.org%2Fpackages%2Fcom.termux%2F)  
   *(или установите клиент F-Droid и установите Termux оттуда).*
2. **GitHub Releases:**  
   Скачайте файл `termux-app_..._universal.apk` из официального репозитория:  
   [github.com/termux/termux-app/releases](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Ftermux%2Ftermux-app%2Freleases)

## ⚡ Шаг 1. Первый запуск и установка VPS Toolkit

После открытия только что установленного Termux на экране появится стандартная командная строка `~ $`.

Вам **не нужно вручную настраивать каждую утилиту** — в установщик `install.sh` встроен **интерактивный мастер проверки окружения (Pre-Flight Check)**, который сам определит недостающие пакеты, задаст понятные вопросы и автоматически всё настроит.

### Команда для запуска установки:

Вставьте в Termux следующую команду и нажмите **Enter**:

```bash
pkg update && pkg install curl -y && curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | bash
```

---

## 🧭 Шаг 2. Что происходит во время установки (Интерактивный мастер)

Установщик последовательно выполнит 4 понятных шага с подробным цветным логом:

### 1. Проверка системных утилит (Pre-Flight Check)
Скрипт проверяет наличие ключевых инструментов:
- `curl` — загрузка скриптов и модулей.
- `openssh` — подключение по SSH и клиент OpenSSH.
- `openssl` — шифрование паролем резервных копий (AES-256).
- `tar` — архивация данных.
- `termux-api` — опционально для копирования ключей в буфер обмена Android.
- `traceroute` — опционально для трассировки сети в модуле NetDiag.

> **Вопрос установщика:**  
> Если какого-то пакета не хватает (например, `openssh`), скрипт выведет:  
> `Обнаружены отсутствующие пакеты: openssh. Установить их автоматически через pkg? [Y/n]:`  
> Нажмите **Enter** (или `Y`) — скрипт сам обновит репозитории и установит их.

---

### 2. Запрос доступа к памяти телефона Android
Для работы с зашифрованными резервными копиями (выгрузка и восстановление из папки «Загрузки») Termux требуется доступ к файловой системе Android.

> **Вопрос установщика:**  
> `Запросить доступ к памяти (termux-setup-storage)? [Y/n]:`  
> Нажмите **Enter**. Во всплывающем системном окне Android нажмите **«Разрешить»**.

---

### 3. Автопоиск бэкапов в папке «Загрузки» и мгновенное восстановление
Установщик проверяет стандартную папку загрузок телефона:  
**`/storage/emulated/0/Download/`** *(доступ только к этой папке для импорта/экспорта бэкапов)*.

* **Поддерживаемые расширения и форматы:**
  * **`*.enc`** — Зашифрованный сейф (содержит список серверов + все приватные ключи под защитой шифра AES-256).
  * **`config-*.bak`** или **`*.bak`** — Простая незашифрованная копия (только текстовый файл `~/.ssh/config`).

* **Автоматическое распознавание типа архива:**
  Скрипт проверяет сигнатуру файла и выводит статус:
  * `[ЗАШИФРОВАН: AES-256 + Ключи]`
  * `[НЕ ЗАШИФРОВАН: Только config]`

> **Вопрос установщика:**  
> `Восстановить серверы и ключи из найденного бэкапа сейчас? [Y/n]:`  
> • При согласии (**Enter / Y**): для файла `.enc` скрипт запросит пароль, расшифрует его, восстановит все серверы и приватные ключи в `~/.ssh/` и автоматически выставит права безопасности Linux (`chmod 700 ~/.ssh`, `chmod 600 id_*`, `chmod 644 *.pub`, `chmod 600 config`).  
> • Если выбрать **n (нет)**: скрипт пропустит шаг и настроит чистое окружение с нуля.

---

### 4. Развёртывание компонентов и создание команд
Установщик скачает все 14 модулей из репозитория GitHub, разместит их в изолированном каталоге и создаст короткие системные команды:
- `vps` (или `vps-toolkit`) — Главный пульт со всеми 14 модулями.
- `ssh-manager` — Менеджер SSH-подключений и серверов.
- `vps-monitor` — Мультисерверный онлайн-мониторинг.
- `netdiag` — Сетевая диагностика.

## 🎯 Шаг 3. Первые шаги после установки

После завершения установки наберите команду:

```bash
vps
```

Откроется главное меню **Android VPS Toolkit**:

```text
════════════════════════════════════════════════════
              ANDROID VPS TOOLKIT                   
      Мобильный командный пульт администрирования   
════════════════════════════════════════════════════
  Настроено серверов: 0

  1. VPS Control Center (SSH Manager)
  2. VPS Monitor (Сводный онлайн-мониторинг)
  ...
  0. Выход
────────────────────────────────────────────────────
Выберите модуль [0–15]: 
```

### Рекомендуемый порядок первого запуска:

1. **Добавление первого сервера:**
   - Нажмите `1` (откроется VPS Control Center).
   - Выберите `2. Добавить сервер`.
   - Введите алиас сервера (например, `my-vps`), IP-адрес, пользователя (`root`) и порт (`22` или `1241`).
2. **Создание SSH-ключа прямо на телефоне:**
   - В меню перейдите в `5. SSH-ключи` -> `2. Создать новый ключ`.
   - Выберите `1. ED25519` (современный, быстрый и надёжный стандарт).
   - Нажмите `6. Установить ключ на VPS` (`ssh-copy-id`), чтобы перенести открытый ключ на сервер в один клик. Теперь вход будет работать без пароля!
3. **Создание зашифрованного сейфа (бэкапа):**
   - Перейдите в `7. Резервные копии` -> `4. 🔒 Экспорт ЗАШИФРОВАННОГО архива в память телефона`.
   - Придумайте пароль.
   - Скрипт зашифрует ваши серверы и приватные ключи алгоритмом **AES-256-CBC** и положит файл `vps-vault-....enc` в папку **«Загрузки»** телефона.

## 🔄 Шаг 4. Как восстановить всё в новый Termux (при переустановке или на новом телефоне)

Если вы сменили телефон или переустановили Termux:
1. Установите Termux и запустите установку VPS Toolkit (Шаг 1).
2. Поместите ваш сохранённый файл `vps-vault-....enc` в папку «Загрузки» телефона.
3. Откройте `vps` -> `7. Резервные копии` -> `5. 🔓 Импорт и расшифровка архива`.
4. Скрипт сам найдёт файл в папке загрузок, спросит пароль, расшифрует ключи и восстановит все серверы со строгими правами безопасности Linux (`chmod 700 / 600`).
5. Всё готово — можно подключаться к серверам в один клик!

## ❓ Частые вопросы и решение проблем

### 1. Ошибка `Permission denied` при установке на Ubuntu
Если вы запускаете установку не на телефоне, а на ПК с **Ubuntu / Debian**, системная переменная `$PREFIX` пустая.  
Используйте команду для обычной пользовательской установки в `~/.local/bin`:
```bash
curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | bash
```

### 2. Как обновить модули до самой последней версии?
В главном меню наберите:
- Либо пункт `15` в меню `vps` (`Синхронизировать / обновить все модули из GitHub`).
- Либо в терминале Termux:
  ```bash
  vps update
  ```

### 3. Безопасно ли хранить ключи в бэкапе?
Да, потому что при экспорте в память телефона используется шифрование OpenSSL **AES-256-CBC** с 100 000 итераций функции PBKDF2. Без знания введённого вами пароля расшифровать файл невозможно.
