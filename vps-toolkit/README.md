**Универсальный мобильный пульт управления Linux VPS, SSH, файлами, сетью и безопасностью в Termux без root.**

Android VPS Toolkit превращает смартфон на Android в карманную консоль системного администратора. Вместо десятков разрозненных скриптов — единая модульная экосистема с общими библиотеками, одинаковым оформлением и навигацией, полностью оптимизированной под цифровую клавиатуру телефона.

---

## ⚡ Быстрая установка (в одну команду)

Откройте Termux и выполните команду:

```bash
pkg update && pkg install curl openssh -y && curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/install.sh?$(date +%s)" | bash
```

После завершения установки в системе доступны удобные команды:

```bash
vps          # Главный командный пульт Android VPS Toolkit
ssh-manager  # VPS Control Center (управление серверами и SSH)
vps-monitor  # Сводный онлайн-мониторинг всех серверов
netdiag      # Сетевая диагностика (Ping, DNS, TCP, SSL, SOCKS5)
```

### 1. 🖥️ VPS Control Center (`ssh-manager`) — Приоритет №1
Основа набора — полнофункциональный SSH Manager:
- **Раздельные экраны с цифровой навигацией**: выбор действий (`0..8`) и серверов (`1..N`) разнесены по разным экранам.
- **Подключение в один клик**: выбор сервера по номеру сразу открывает безопасную сессию OpenSSH.
- **Мастер хостов**: пошаговое добавление, редактирование через черновик с сохранением всех директив (`ProxyJump`, `IdentityFile`, `ServerAliveInterval`), безопасное клонирование и удаление.
- **Управление SSH-ключами**: генерация пар ED25519/RSA 4096, проверка отпечатков (SHA256), установка на VPS в `authorized_keys` в один клик (`ssh-copy-id`), интеграция с GitHub.
- **Резервные копии**: автоматическое создание бэкапов `~/.ssh/config` с файлами метаданных `.meta` (дата, размер, контрольная сумма SHA256).

### 2. 📊 VPS Monitor (`vps-monitor`)
Сводный дашборд реального времени по всем серверам:
- Задержка отклика TCP (Ping/Handshake в мс).
- Загрузка CPU (loadavg) и использование RAM (free -m).
- Заполненность дискового пространства root-раздела (`/`).
- Время непрерывной работы (Uptime).
- Статус ключевых служб: Docker, Nginx, 3x-ui, WARP, WireGuard.
- Быстрое обновление данных клавишей `1` (Refresh).

### 3. 📂 SFTP File Manager (`vps-sftp`)
Файловый менеджер для удалённых Linux-серверов:
- Интерактивная навигация по каталогам (`/etc`, `/opt`, `/var/log`, `/root`).
- Просмотр текстовых конфигураций и логов с экрана смартфона.
- Скачивание файлов с VPS в локальную папку `~/downloads/`.
- Загрузка локальных файлов на сервер.
- Быстрый запуск полнофункциональной сессии SFTP.

### 4. 🛡️ VPS Security Audit (`vps-security`)
Экспресс-проверка защищённости серверов в безопасном режиме Read-Only:
- Проверка правил и статуса сетевого экрана UFW / iptables.
- Аудит конфигурации входа SSH (`PermitRootLogin`, `PasswordAuthentication`, нестандартный порт).
- Статус сервиса защиты от подбора паролей Fail2ban.
- Анализ последних неудачных попыток входа (брутфорс в `auth.log` / `journalctl`).
- Список открытых и прослушиваемых TCP/UDP портов (`ss -tulpn`).
- Проверка наличия неустановленных обновлений безопасности.

### 5. 🌐 NetDiag — Сетевая диагностика (`netdiag`)
Инструмент для поиска сетевых неполадок (почему не открывается сайт, не работает прокси или отвалился VPS):
- **Ping**: измерение задержки и проверка потерь пакетов.
- **Traceroute**: трассировка сетевых маршрутов до узла.
- **DNS Lookup**: проверка разрешения записей через Cloudflare (1.1.1.1) и Google (8.8.8.8).
- **Проверка TCP-портов**: мгновенная проверка доступности сокетов (22, 443, 1241 и др.).
- **HTTP/HTTPS и SSL**: проверка кодов ответа, времени рукопожатия и срока годности SSL-сертификатов.
- **Мой внешний IP**: определение внешнего IPv4/IPv6 и страны выхода.
- **SOCKS5/WARP тест**: проверка работоспособности локальных прокси (Xray, WARP, NaïveProxy).

### 6. 🧹 Termux Maintenance (`termux-maintenance`)
Инструменты поддержания здоровья локального окружения Termux:
- Проверка свободного места во внутренней памяти.
- Очистка кэша пакетов `apt` / `pkg clean`.
- Удаление неиспользуемых зависимостей `apt autoremove`.
- Обновление репозиториев и установленных утилит.
- Проверка системных прав `termux-setup-storage`.

## 🔒 Безопасность и приватность

1. **Никаких зашитых серверов**: в репозитории нет личных IP-адресов, паролей, имён серверов или ключей. Код чист и безопасен для публикации на GitHub.
2. **Локальное хранение**: все подключения, приватные ключи и настройки хранятся строго в локальном каталоге `~/.ssh/` на вашем телефоне.
3. **Защита `.gitignore`**: файл `.gitignore` настроен на исключение любых конфигураций (`config*`), бэкапов (`*.backup-*`), приватных ключей (`id_*`, `*.key`) и `known_hosts`.
4. **Безагентная архитектура**: для работы не требуется устанавливать сторонние демоны или агенты на ваши VPS — все операции выполняются через официальный OpenSSH.
