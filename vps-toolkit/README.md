# Android VPS Toolkit 📱 ⚡ 🛠️

**Универсальный мобильный пульт управления Linux VPS, SSH, файлами, сетью и безопасностью в Termux и Linux.**

Android VPS Toolkit превращает смартфон на Android в полноценную карманную консоль системного администратора. Вместо десятков разрозненных скриптов — единая модульная экосистема с общими библиотеками, одинаковым оформлением и навигацией, полностью оптимизированной под цифровую клавиатуру телефона (`0..15`).

## 📖 Руководство: Настройка Termux с нуля и запуск

### ⚠️ Шаг 0. Откуда правильно устанавливать Termux

> **Важнейшее предупреждение:**
>
> **Никогда не устанавливайте Termux из Google Play Store!**
>
> Версия в Google Play официально заброшена разработчиками с 2020 года из-за ограничений политики Google. В ней отключены обновления, и при первой же попытке выполнить `pkg install` вы получите ошибки `Repository under maintenance` или `404 Not Found`.

**Официальные источники для загрузки актуального Termux:**

1. **F-Droid (Рекомендуется):**

   Скачайте APK со страницы [f-droid.org/packages/com.termux/](https://www.google.com/search?q=https%3A%2F%2Ff-droid.org%2Fpackages%2Fcom.termux%2F)

   *(или установите клиент F-Droid и установите Termux оттуда).*

2. **GitHub Releases:**

   Скачайте файл `termux-app_..._universal.apk` из официального репозитория:

   [github.com/termux/termux-app/releases](https://www.google.com/search?q=https%3A%2F%2Fgithub.com%2Ftermux%2Ftermux-app%2Freleases)

### ⚡ Шаг 1. Быстрая установка одной командой

После открытия только что установленного Termux на экране появится стандартная командная строка `~ $`.

Вам **не нужно вручную настраивать утилиты** — в установщик `install.sh` встроен **интерактивный мастер проверки окружения (Pre-Flight Check)**, который сам определит недостающие пакеты, задаст понятные вопросы и автоматически всё настроит.

#### Команда для Termux (на телефоне Android):

```
pkg update && pkg install curl -y && curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | bash

```

#### Команда для Ubuntu / Debian / WSL (на ПК или сервере):

* **Без root / sudo (в домашний каталог пользователя `~/.local/bin`):**

  ```
  curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | bash
  
  ```

* **Общесистемно для всех пользователей (с sudo):**

  ```
  curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | sudo bash
  
  ```

### 🧭 Шаг 2. Что происходит во время установки (Интерактивный мастер)

Установщик последовательно выполнит 3 понятных шага с цветным логом:

1. **Проверка системных утилит (Pre-Flight Check):**
   Скрипт проверяет наличие ключевых инструментов:

   * `curl` — загрузка скриптов и модулей.

   * `openssh` — подключение по SSH и клиент OpenSSH.

   * `openssl` — шифрование паролем резервных копий (AES-256).

   * `tar` — архивация данных.

   * `termux-api` — опционально для копирования ключей в буфер обмена Android.

   * `traceroute` — опционально для трассировки сети в модуле NetDiag.

   > **Вопрос установщика:**
   >
   > Если пакетов не хватает, скрипт выведет:
   >
   > `Обнаружены отсутствующие пакеты: openssh termux-api. Установить их автоматически через pkg? [Y/n]:`
   >
   > Нажмите **Enter** — скрипт сам обновит репозитории и установит их.

2. **Запрос доступа к памяти телефона Android:**
   Для работы с зашифрованными резервными копиями (чтобы бэкап можно было выгрузить в папку «Загрузки» телефона и сохранить на Google Диск) Termux требуется доступ к файловой системе Android.

   > **Вопрос установщика:**
   >
   > `Запросить доступ к памяти (termux-setup-storage)? [Y/n]:`
   >
   > Нажмите **Enter**. Во всплывающем системном окне Android нажмите **«Разрешить»**.

3. **Развёртывание компонентов и создание команд:**
   Скрипт загрузит все 14 модулей из репозитория GitHub и создаст удобные команды в системе:

   * `vps` (или `vps-toolkit`) — Главный пульт со всеми 14 модулями.

   * `ssh-manager` — Менеджер SSH-подключений и серверов.

   * `vps-monitor` — Мультисерверный онлайн-мониторинг.

   * `netdiag` — Сетевая диагностика.

## ❓ Включает ли VPS Toolkit функции SSH Manager или это разные скрипты?

**VPS Toolkit полностью включает в себя все функции SSH Manager!** Они работают как единая экосистема:

1. **`ssh-manager.sh` является ядром и модулем №1 (VPS Control Center)** внутри `vps-toolkit.sh`.

2. При выборе пункта **`1. VPS Control Center (SSH Manager)`** в главном меню `vps` запускается тот самый полнофункциональный менеджер серверов со всеми возможностями: подключение к серверам, добавление, редактирование через черновик, клонирование, ключи, конфиг, бэкапы.

3. При этом **`ssh-manager.sh` остаётся полностью автономным**: его можно запускать как из главного меню `vps`, так и отдельной командой `ssh-manager` в терминале.

4. **Все 14 модулей используют один и тот же источник данных** — ваш локальный файл `~/.ssh/config`. Добавив сервер в SSH Manager, вы сразу видите его в мониторинге, SFTP, аудите безопасности и логах.

## 🧰 Подробное описание всех 14 модулей (Что уже добавлено)

| № | Модуль | Исполняемый файл | Что делает | 
| ----- | ----- | ----- | ----- | 
| **1** | **VPS Control Center** | `ssh-manager.sh` | **Флагман**: подключение в один клик (`1..N`), мастер добавления хостов с валидацией портов, редактирование через черновик с сохранением всех директив (`ProxyJump`, `IdentityFile`, `ServerAliveInterval`), клонирование, удаление, аудит прав `~/.ssh/` (`700/600/644`). | 
| **2** | **VPS Monitor** | `modules/vps-monitor.sh` | **Мультисерверный дашборд**: замер задержки TCP (мс), сбор нагрузки CPU (`loadavg`), памяти (`free -m`), диска (`df -h /`), аптайма и статуса ключевых служб (Docker, Nginx, 3x-ui, WARP, WireGuard) по всем серверам сразу. | 
| **3** | **SFTP File Manager** | `modules/vps-sftp.sh` | **Файловый менеджер**: навигация по каталогам (`/etc`, `/opt`, `/var/log`), просмотр конфигов на экране телефона, скачивание файлов в `~/downloads/`, загрузка файлов на сервер, запуск консоли SFTP. | 
| **4** | **VPS Security Audit** | `modules/vps-security.sh` | **Аудит безопасности (Read-Only)**: проверка правил сетевого экрана UFW, настроек входа в `sshd_config`, статуса Fail2ban, поиск попыток брутфорса в `auth.log` и доступных обновлений безопасности `apt`. | 
| **5** | **NetDiag** | `modules/net-diag.sh` | **Сетевой комбайн**: Ping, Traceroute, проверка DNS (Cloudflare 1.1.1.1 и Google 8.8.8.8), проверка доступности любых TCP-портов со смартфона, проверка HTTP/HTTPS и сроков SSL-сертификатов, внешний IP, SOCKS5-тест. | 
| **6** | **Backup Manager** | `modules/backup-manager.sh` | **Резервные копии и Защищённый сейф**: локальные бэкапы `config` с метаданными `.meta`, а также **шифрование AES-256-CBC с приватными ключами** и выгрузка в память телефона (папка «Загрузки») для переноса в новый Termux в один клик. | 
| **7** | **Docker Manager** | `modules/docker-manager.sh` | **Контейнеры Docker**: список контейнеров (`docker ps -a`), чтение логов (`docker logs --tail`), перезапуск, остановка, запуск, просмотр потребления ресурсов (`docker stats`) и очистка образов (`docker system prune`). | 
| **8** | **Service Manager** | `modules/service-manager.sh` | **Службы systemd**: статус сервисов (nginx, ssh, docker, fail2ban, ufw, 3x-ui, warp), подробный вывод `systemctl status`, запуск, остановка и перезапуск с подтверждением, чтение журнала службы (`journalctl -u`). | 
| **9** | **Log Viewer** | `modules/log-viewer.sh` | **Просмотр логов**: системные ошибки высокого приоритета (`journalctl -p 3 -xb`), логи авторизаций SSH (`auth.log` / `journalctl -u ssh`), журнал ядра (`dmesg`), ошибки Nginx и произвольные лог-файлы в `/var/log/`. | 
| **10** | **Port Scanner** | `modules/port-scanner.sh` | **Аудит портов**: внутренний список слушающих служб (`ss -tulpn LISTEN`), внешнее сканирование доступности диапазона портов со стороны телефона и проверка сторонних хостов. | 
| **11** | **Git Deploy** | `modules/git-deploy.sh` | **Развёртывание Git**: статус репозиториев на сервере, просмотр коммитов (`git log`), `git pull` с созданием страховочного `.tar.gz` архива перед обновлением, просмотр `git diff`, откат изменений. | 
| **12** | **Termux Maintenance** | `modules/termux-maintenance.sh` | **Обслуживание Termux**: проверка свободного места во внутренней памяти Android, очистка кэша пакетов `pkg clean`, удаление зависимостей `apt autoremove`, обновление `pkg update`. | 
| **13** | **SSH Key Manager** | `modules/ssh-key-manager.sh` | **Управление ключами**: список локальных ключей и отпечатков SHA256, генерация пар ED25519/RSA 4096 с правами `600/644`, экспорт `.pub` в буфер обмена Android, отправка ключа на VPS в один клик (`ssh-copy-id`), импорт из GitHub. | 
| **14** | **Quick Commands** | `modules/quick-commands.sh` | **Быстрые команды**: библиотека частых однострочников (очистка диска, перезапуск стека, память/swap) с запуском в один клик и возможностью добавления своих команд. |

## 🔒 Безопасность данных и приватность

1. **Никаких зашитых серверов**: в репозитории нет личных IP-адресов, паролей, имён серверов или ключей. Код чист и безопасен для публикации на GitHub.

2. **Локальное хранение**: все подключения, приватные ключи и настройки хранятся строго в локальном каталоге `~/.ssh/` на вашем телефоне.

3. **Защита `.gitignore`**: файл `.gitignore` настроен на исключение любых конфигураций (`config*`), бэкапов (`*.backup-*`), приватных ключей (`id_*`, `*.key`) и `known_hosts`.

4. **Безагентная архитектура**: для работы не требуется устанавливать сторонние демоны или агенты на ваши VPS — все операции выполняются через официальный OpenSSH.
