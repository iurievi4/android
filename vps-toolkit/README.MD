**Универсальный мобильный пульт управления Linux VPS, SSH, файлами, сетью и безопасностью в Termux и Linux.**

Android VPS Toolkit превращает смартфон на Android в полноценную карманную консоль системного администратора. Вместо десятков разрозненных скриптов — единая модульная экосистема с общими библиотеками, одинаковым оформлением и навигацией, полностью оптимизированной под цифровую клавиатуру телефона (`0..15`).

---

## ⚡ Быстрая установка

### 1. Для Termux (на телефоне Android):
Откройте Termux и выполните одну команду:

```bash
pkg update && pkg install curl openssh -y && curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | bash
```

### 2. Для Ubuntu / Debian / WSL (на ПК или сервере):
* **Без root / sudo (установка в домашний каталог пользователя `~/.local/bin`):**
  ```bash
  curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | bash
  ```
* **Общесистемная установка для всех пользователей (с sudo):**
  ```bash
  curl -fsSL -H "Cache-Control: no-cache" "https://raw.githubusercontent.com/iurievi4/android/main/vps-toolkit/install.sh?$(date +%s)" | sudo bash
  ```

## 🚀 Команды запуска после установки

После установки в системе доступны удобные команды:

| Команда | Описание |
| :--- | :--- |
| **`vps`** (или **`vps-toolkit`**) | **Главный пульт управления Android VPS Toolkit** (меню со всеми 14 модулями) |
| **`ssh-manager`** | **VPS Control Center** (управление серверами, подключение, ключи, конфиг) |
| **`vps-monitor`** | Прямой запуск сводного онлайн-мониторинга всех серверов |
| **`netdiag`** | Прямой запуск сетевой диагностики (Ping, DNS, TCP, SSL, SOCKS5) |

## ❓ Включает ли VPS Toolkit функции SSH Manager или это разные скрипты?

**VPS Toolkit полностью включает в себя SSH Manager!** Они спроектированы как единая система:

1. **`ssh-manager.sh` является ядром и модулем №1 (VPS Control Center)** внутри `vps-toolkit.sh`.
2. При выборе пункта **`1. VPS Control Center (SSH Manager)`** в главном меню `vps` запускается тот самый полнофункциональный менеджер серверов со всеми возможностями (подключение, добавление серверов, ключи, конфиг, бэкапы).
3. При этом **`ssh-manager.sh` остаётся полностью автономным**: его можно запускать как из главного меню `vps`, так и отдельной командой `ssh-manager` в терминале.
4. **Все 14 модулей используют один и тот же источник данных** — ваш локальный файл `~/.ssh/config`. Добавив сервер в SSH Manager, вы сразу видите его в мониторинге, SFTP, аудите безопасности и логах.

### 1. 🖥️ VPS Control Center (`ssh-manager.sh`) — Флагман
Центральный пульт управления подключениями к серверам:
- **Раздельные экраны с цифровой навигацией**: в главном меню выбираются действия (`0..8`), а на экране подключения — серверы (`1..N`).
- **Подключение в один клик**: мгновенный вход в сессию OpenSSH с корректным возвратом в менеджер по завершении (`exit`).
- **Мастер хостов**: пошаговое добавление серверов, валидация портов (1–65535), редактирование через черновик с сохранением всех нестандартных параметров OpenSSH (`ProxyJump`, `IdentityFile`, `ServerAliveInterval`), безопасное клонирование и удаление с подтверждением.
- **Работа с SSH Config**: просмотр эффективных параметров через `ssh -G`, аудит и автоисправление прав доступа (`700`/`600`/`644`).
- **Автоматический бэкап**: создание копии `config.backup-YYYY-MM-DD-HHMMSS` перед каждым изменением файла.

### 2. 📊 VPS Monitor (`modules/vps-monitor.sh`)
Сводный дашборд реального времени по всем серверам сразу:
- **Задержка TCP**: измерение отклика в миллисекундах по сокету без задержек.
- **Нагрузка системы**: сбор метрик CPU (`loadavg`), использование памяти (`free -m`), заполненность диска (`df -h /`).
- **Время работы**: статус Uptime сервера.
- **Статус ключевых служб**: опрос Docker, Nginx, 3x-ui / x-ui, WARP, WireGuard.
- **Быстрое обновление**: обновление информации нажатием `1` (Refresh).

### 3. 📂 SFTP File Manager (`modules/vps-sftp.sh`)
Файловый менеджер для удалённых серверов через штатные протоколы SFTP/SCP:
- **Навигация по каталогам**: интерактивный обзор `/etc`, `/opt`, `/var/log`, `/root`.
- **Просмотр файлов**: чтение текстовых конфигураций и логов с экрана смартфона.
- **Скачивание на телефон**: загрузка файлов с VPS в папку `~/downloads/` на устройстве.
- **Загрузка на VPS**: отправка локальных файлов с телефона на сервер.
- **Интерактивный SFTP**: быстрый запуск консоли SFTP для комплексных файловых операций.

### 4. 🛡️ VPS Security Audit (`modules/vps-security.sh`)
Экспресс-проверка защищённости серверов в безопасном режиме Read-Only:
- **Сетевой экран**: проверка статуса и правил UFW / iptables.
- **Аудит SSH**: проверка директив `PermitRootLogin`, `PasswordAuthentication` и нестандартного порта в `sshd_config`.
- **Fail2ban**: статус работы защиты от подбора паролей.
- **Анализ атак**: обнаружение попыток брутфорса и неудачных входов в `auth.log` / `journalctl`.
- **Прослушиваемые порты**: список открытых сокетов (`ss -tulpn`).
- **Обновления**: проверка наличия неустановленных патчей безопасности `apt`.

### 5. 🌐 NetDiag — Сетевая диагностика (`modules/net-diag.sh`)
Инструмент для поиска сетевых неполадок (почему не подключается сервер, отвалился прокси или сайт):
- **Ping**: измерение задержки и потерь пакетов до узла.
- **Traceroute**: трассировка маршрута прохождения пакетов.
- **DNS Lookup**: проверка разрешения записей через Cloudflare (1.1.1.1) и Google (8.8.8.8).
- **Проверка TCP-портов**: проверка доступности любого порта со смартфона (22, 443, 1241 и др.).
- **HTTP/HTTPS и SSL**: коды ответа, время соединения и срок действия SSL-сертификатов.
- **Мой внешний IP**: определение внешнего IPv4/IPv6 телефона и страны выхода.
- **SOCKS5/WARP тест**: проверка работоспособности прокси (WARP, Xray, NaïveProxy).

### 6. 💾 Backup Manager (`modules/backup-manager.sh`)
Резервные копии и безопасность конфигураций:
- Создание резервных копий `~/.ssh/config` с формированием файлов метаданных `.meta` (дата, размер, контрольная сумма SHA256, список серверов).
- Просмотр списка существующих бэкапов.
- Безопасное восстановление с проверкой целостности хеша SHA256 и созданием страховочной копии текущего состояния.
- Автоматическая ротация старых резервных копий.

### 7. 🐳 Docker Manager (`modules/docker-manager.sh`)
Управление контейнерами Docker на удалённых серверах:
- Список всех контейнеров (`docker ps -a`) с их статусами и портами.
- Просмотр логов любого контейнера (`docker logs --tail`).
- Перезапуск, остановка и запуск контейнеров с телефона.
- Мониторинг ресурсов (`docker stats --no-stream`).
- Список образов (`docker images`) и очистка (`docker system prune`).

### 8. ⚙️ Service Manager (`modules/service-manager.sh`)
Управление системными службами `systemd`:
- Экспресс-проверка статусов ключевых служб (nginx, ssh, docker, fail2ban, ufw, 3x-ui, warp-svc).
- Подробный статус любой службы (`systemctl status`).
- Перезапуск, остановка и запуск служб с обязательным подтверждением.
- Просмотр журнала конкретной службы (`journalctl -u`).
- Список всех работающих служб Linux.

### 9. 📜 Log Viewer (`modules/log-viewer.sh`)
Просмотр и фильтрация системных логов:
- Ошибки системы высокого приоритета (`journalctl -p 3 -xb`).
- Журнал авторизаций SSH (`auth.log` / `journalctl -u ssh`).
- Логи ядра и оборудования (`dmesg`).
- Логи ошибок веб-сервера Nginx (`error.log`).
- Просмотр произвольного файла лога в каталоге `/var/log/`.

### 10. 🔌 Port Scanner (`modules/port-scanner.sh`)
Проверка портов и сокетов:
- Внутренний аудит: просмотр всех служб в режиме `LISTEN` на сервере (`ss -tulpn`).
- Внешнее сканирование: проверка доступности диапазона портов снаружи со смартфона.
- Проверка произвольного стороннего IP или домена.

### 11. 🐙 Git Deploy (`modules/git-deploy.sh`)
Управление Git-репозиториями проектов на серверах:
- Проверка статуса репозитория (`git status`) и последних коммитов (`git log`).
- Загрузка обновлений (`git pull`) с созданием страховочного `.tar.gz` архива перед пулом.
- Просмотр изменений (`git diff`).
- Откат незакоммиченных изменений (`git reset --hard HEAD`).

### 12. 🧹 Termux Maintenance (`modules/termux-maintenance.sh`)
Обслуживание и оптимизация среды Termux на телефоне:
- Проверка свободного места во внутренней памяти.
- Очистка кэша пакетов `apt` / `pkg clean`.
- Удаление неиспользуемых зависимостей `apt autoremove`.
- Обновление репозиториев и установленных утилит `pkg update`.
- Проверка системного доступа к памяти `termux-setup-storage`.

### 13. 🔑 SSH Key Manager (`modules/ssh-key-manager.sh`)
Управление SSH-ключами:
- Список установленных ключей в `~/.ssh/` с выводом типов и отпечатков SHA256.
- Генерация новых пар ED25519 или RSA 4096 с защитой от перезаписи и корректными правами (`600`/`644`).
- Экспорт открытого ключа `.pub` на экран и копирование в буфер обмена Android (через `termux-api`).
- Установка ключа на VPS в один клик (`ssh-copy-id`).
- Загрузка публичных ключей из вашего профиля GitHub (`https://github.com/<user>.keys`).

### 14. ⚡ Quick Commands (`modules/quick-commands.sh`)
Библиотека быстрых команд и однострочников:
- Выполнение частых административных задач на сервере в один клик.
- Просмотр списка предустановленных команд.
- Добавление собственных пользовательских команд прямо со смартфона с сохранением в `~/.ssh/quick-commands.list`.

## 🔒 Безопасность данных и приватность

1. **Никаких зашитых серверов**: в репозитории нет личных IP-адресов, паролей, имён серверов или ключей. Код чист и безопасен для публикации на GitHub.
2. **Локальное хранение**: все подключения, приватные ключи и настройки хранятся строго в локальном каталоге `~/.ssh/` на вашем телефоне.
3. **Защита `.gitignore`**: файл `.gitignore` настроен на исключение любых конфигураций (`config*`), бэкапов (`*.backup-*`), приватных ключей (`id_*`, `*.key`) и `known_hosts`.
4. **Безагентная архитектура**: для работы не требуется устанавливать сторонние демоны или агенты на ваши VPS — все операции выполняются через официальный OpenSSH.
