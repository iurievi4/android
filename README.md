# Termux SSH Manager 📱 🔑

![Bash](https://img.shields.io/badge/Language-Bash-4EAA25?logo=gnu-bash&logoColor=white)
![Platform](https://img.shields.io/badge/Platform-Termux%20%7C%20Android-green?logo=android&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-blue)

Легковесная и удобная интерактивная консольная утилита на чистом Bash для управления SSH-подключениями, файлом `~/.ssh/config` и ключами авторизации в среде Termux на Android.

---

## ⚡ Быстрая установка (в одну команду)

Откройте Termux и выполните команду:

```bash
pkg update && pkg install curl openssh -y && curl -fsSL https://raw.githubusercontent.com/iurievi4/android/main/ssh-manager.sh -o $PREFIX/bin/ssh-manager && chmod +x $PREFIX/bin/ssh-manager
```

После завершения установки утилита доступна из любого каталога:

```bash
ssh-manager
```

## ✨ Основные возможности

### 🖥️ Управление серверами
- **Интерактивное меню**: мгновенное подключение к серверу по нажатию его цифры.
- **Единый источник истины**: работает напрямую с вашим `~/.ssh/config` без сторонних баз данных и синхронизаций. По умолчанию список пуст и заполняется только вашими серверами.
- **Два режима авторизации**:
  - **По SSH-ключу**: привязка ключа с выбором из существующих на устройстве или ключа по умолчанию.
  - **По паролю**: отключение проверки ключей (`PubkeyAuthentication no`), чтобы исключить задержки и ошибки несовпадения ключей. Пароли не сохраняются в открытом виде — их безопасно запрашивает OpenSSH.
- **Безопасное добавление и удаление**: пошаговый мастер добавления и подтверждение точного имени сервера при удалении.
- **Автоматический бэкап**: создание резервной копии `config.backup-YYYY-MM-DD-HHMMSS` перед каждым изменением файла (с автоматической ротацией до 10 последних копий).
- **Встроенная диагностика**: проверка доступности порта и SSH-соединения (`T`).

### 🔑 Управление SSH-ключами
- **Просмотр установленных ключей**: сканирование каталога `~/.ssh/` с выводом имён и отпечатков (fingerprints).
- **Генерация ключей**: быстрое создание новых пар ключей **ED25519** или **RSA 4096** с корректными правами доступа (`600` / `644`).
- **Экспорт публичного ключа**: вывод `.pub` на экран и автоматическое копирование в буфер обмена Android (при наличии `termux-api`).
- **Отправка ключа на сервер (`ssh-copy-id`)**: перенос ключа на VPS в один клик для беспарольного входа.
- **Удаление ключей**: безопасное удаление связок ключей с подтверждением.

## 🔒 Безопасность данных

- **Все приватные ключи и файл `~/.ssh/config` остаются исключительно на вашем телефоне.**
- Репозиторий содержит исключительно код утилиты.
- Файл `.gitignore` блокирует попадание любых конфигурационных файлов, бэкапов (`*.backup-*`), приватных ключей (`id_*`, `*.key`) и `known_hosts` в систему контроля версий.
